# Project Statement

## 1. Project Title

Personal Expense Tracker

## 2. Problem Statement

Managing daily expenses manually can make it difficult for users to keep
track of their spending. Users may forget individual expenses, find it
difficult to calculate total spending, or have difficulty understanding
where their money is being spent.

The Personal Expense Tracker provides a simple Python-based solution for
recording, managing, and analyzing personal expenses.

## 3. Scope of the Project

The project focuses on managing personal expenses through a menu-driven
Python application.

The system allows users to:

- Add expenses
- View expenses
- Update expenses
- Delete expenses
- Set a monthly budget
- Check budget status
- Calculate total expenses
- View category-wise spending
- View monthly spending
- Identify the highest expense

Expense records are stored in a CSV file.

The project also includes input validation, error handling, testing, and
documentation.

## 4. Target Users

The target users of this project are:

- Students
- Individuals
- People who want to monitor their daily spending
- Users who want a simple expense management system

## 5. High-Level Features

### Expense Management

Users can add, view, update, and delete expense records.

### Budget Management

Users can set a monthly budget and check their spending against the budget.

### Reports and Analytics

The system provides total expenses, category summaries, monthly summaries,
and the highest expense.

### Data Storage

Expense information is stored in a CSV file so that the data can be loaded
again when the application is started.

### Input Validation

The system validates dates, amounts, categories, descriptions, and other
user inputs.

### Error Handling

The application handles invalid input and provides appropriate messages to
the user.

## 6. Objectives

The main objectives of the project are:

- To develop a simple personal expense management application.
- To provide an organized way to record expenses.
- To allow users to monitor their spending.
- To provide budget management functionality.
- To generate useful expense summaries and reports.
- To demonstrate modular Python programming.
- To implement data validation and error handling.
- To apply testing and version control using Git and GitHub.
